5. Hexagon Relocation Reference

5.1. Introduction

Hexagon is a VLIW DSP architecture where all instructions are 32 bits wide. Relocations encode symbol references into instruction immediate fields. The Hexagon ABI supports an extended relocation pair mechanism for large offsets: a non-extended relocation encodes the low 6 bits, while a paired _X-suffix relocation encodes the upper bits of the value.

5.2. GOT/PLT Allocation Annotations

Modes: S = static executable, D = dynamic executable, P = PIE, H = shared library; I overrides P for static PIE. Resources: G = symbol GOT slot, J = PLT destination GOT slot, L = PLT entry, R = IFUNC resolver PLT; - = no allocation. Conditions: p = Preemptible=true, f = function, i = IFUNC, g = global-bound, t = TLS, h = local-bound hidden. [a&b] requires both conditions; ! means NOT. Unconditional entries apply to any visibility/type. TLS resources, modifiers, and examples are in the shared annotation legend; see also the preemption flowchart.

  • GOT_32_6_X and GOT_11_X allocate symbol-address slots for local and global targets. Other ordinary GOT_* variants allocate them only for non-local targets; their local-symbol scanner has no matching case. GOTREL_* creates only the shared GOT base, not a target-symbol slot. The local scanner skips hidden targets except for GOT_32_6_X and GOT_11_X; the h condition identifies these exceptions.

  • Absolute/GP-relative function references use Preemptible=true and STT_FUNC. Branch/PC-relative references use Preemptible=true only in non-static links, including extended branches and 32_PCREL/6_PCREL_X, without a function-type test for PLT allocation.

  • Static weak-undefined branch references can target __linker_guard_weak_undef (unless disabled), not a PLT. Extended branches qualify for this guard only with STT_FUNC.

  • Range stubs check signed D >> 2, with D = target + A - P. B22_PCREL, PLT_B22_PCREL, and non-extended GD/LD PLT calls have ±8 MiB reach; B15_PCREL ±64 KiB, B13_PCREL ±16 KiB, and B9_PCREL ±1 KiB. B7_PCREL has no range trampoline, despite its finite range. Extended _X forms do not request range stubs. Range testing does not require STT_FUNC; the target can be a selected PLT address, and PIC/non-PIC templates differ.

  • TLS GD GOT references create a GD pair in dynamic links, or an IE slot plus a GD-to-IE access stub in static links. LD shares the module slot; IE reserves a slot in every mode. These require STT_TLS.

  • GD/LD PLT-call relocations are retargeted: static links use GD-to-IE / LD-to-LE access stubs; dynamic links reserve a PLT for a resolver stub, not the original TLS symbol. Access stubs are model-driven, not distance-driven. Non-extended calls can additionally need range stubs.

Sources: scanner / TLS creation, range stub, TLS stub.

5.3.1. Extended Relocation Pair Mechanism

For branch or absolute references that exceed the reach of a single immediate field, Hexagon uses a two-relocation sequence:

  • R_HEX_B32_PCREL_X (or R_HEX_32_6_X for absolute) encodes bits [31:6] of the value into a 32-bit instruction immediate using a 26-bit field with shift 6.

  • R_HEX_B*_PCREL_X / R_HEX_*_X (the non-extended counterpart) encodes bits [5:0] of the value into a 6-bit field with no shift.

Relocations with the _X suffix are the upper-bits half of such a pair. The lower-bits half uses R_HEX_6_PCREL_X (PC-relative) or a corresponding R_HEX_*_X variant (absolute).

5.3.2. Table Columns

Column

Meaning

EffectiveBits

Number of significant bits checked after the shift is applied

Shift

Right-shift applied to the value before encoding and before the range check

Signed

Whether the field is treated as a signed two’s-complement value

Range check

Exact inequality the linker enforces on the raw value X; — means no check

Alignment check

Exact divisibility condition the linker enforces on the raw value X; — means no check

How the checks work. Let X be the raw relocation value (e.g. S+A-P).

  • Range (signed, N bits, shift S): -(2^(N-1) × 2^S) ≤ X < 2^(N-1) × 2^S — i.e. X >> S fits in a signed N-bit field.

  • Range (unsigned, N bits, shift S): 0 ≤ X < 2^N × 2^S — i.e. X >> S fits in an unsigned N-bit field.

  • Alignment: X % A == 0 where A is the per-relocation alignment requirement shown in the check expression.
