1. AArch64 Relocation Reference

1.1. Introduction

AArch64 relocation operators such as :abs_g0_nc:, :pg_hi21:, and :lo12: instruct the assembler and linker how to encode symbol references into instruction immediate fields.

1.2. GOT/PLT Allocation Annotations

Modes: S = static executable, D = dynamic executable, P = PIE, H = shared library; I overrides P for static PIE. Resources: G = symbol GOT slot, J = PLT destination GOT slot, L = PLT entry, R = IFUNC resolver PLT; - = no allocation. Conditions: p = Preemptible=true, f = function, i = IFUNC, g = global-bound, t = TLS, h = local-bound hidden. [a&b] requires both conditions; ! means NOT. Unconditional entries apply to any visibility/type. TLS resources, modifiers, and examples are in the shared annotation legend; see also the preemption flowchart.

  • Ordinary GOT-page/load references reserve a slot for any visibility, symbol type, or link mode. The global-bound static IFUNC scan path uses the PLT-associated GOT slot instead; local-bound symbols take the ordinary local scanner.

  • CONDBR19, JUMP26, and CALL26 use Preemptible=true without a STT_FUNC check; TSTBR14 does not request an ordinary PLT. ADRP and absolute function-address references use Preemptible=true and STT_FUNC. PREL data references use it only for non-DynObj output; PIE has DynObj output kind.

  • The static IFUNC scanner can warn and still reserve a PLT for invalid IFUNC address forms. MOVW forms and literal loads are not classified as valid IFUNC address sequences; MOVW_UABS_G1_NC and PREL data forms additionally have unsupported-IFUNC warnings.

  • Only CALL26/JUMP26 have range stubs. For D = target + A - P, the current predicate is abs(D >> 2) < 2^25 (nominal ±128 MiB). It requests a stub at the negative architectural endpoint too. The relaxation pass skips undefined targets; the stub predicate also exempts undefined weak non-DSO targets without a PLT. The target can be a PLT address; neither visibility nor STT_FUNC adds a range test. PIC and non-PIC templates differ. TSTBR14/CONDBR19 overflow is an error.

  • TLS IE omits the GOT for local-bound static targets (instruction conversion); global-bound static targets still reserve an IE slot. Dynamic links reserve IE slots for both local and global targets. TLSDESC address/load/add references use an IE slot for static or non-preemptible executable targets; preemptible executable and shared-library targets use descriptors. TLSDESC_CALL itself reserves neither GOT nor ordinary function PLT.

Sources: scanner, range stub.

Alignment: All four control-flow relocations encode X >> 2 into their immediate field, so X (S+A-P) must be divisible by 4. The linker emits an error if X & 3 != 0.

Out-of-range (JUMP26/CALL26): When the branch target is beyond ±128 MB the linker inserts a trampoline stub for range extension, including when the destination is a PLT entry. If trampolines are disabled with --no-trampolines, the relocation instead reports an overflow error. The displacement is required to be 4-byte aligned and fit in the signed 28-bit range. TSTBR14 and CONDBR19 have no trampoline support; exceeding their range is a hard error.
